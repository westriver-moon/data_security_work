# 数据安全系统设计与实践

本仓库保存课程项目的完整 Python 源码。项目包括数据资产治理、用途决策、安全共享、跨机构联合分析和使用追踪五个任务，由根目录 `main.py` 调度，公共功能在 `utils.py`。

## 目录

```text
main.py                         # 根入口
utils.py                        # 公共数据、规则、运行与结果管理
requirements.txt                # Python 依赖
01_数据资产盘点与质量治理/       # TODO 01–03
02_数据流转分析与使用决策/       # TODO 04–05
03_数据共享与安全发布/           # TODO 06–08
04_跨机构联合分析/               # TODO 09–11
05_数据使用管理与过程追踪/       # TODO 12–14
```

每个任务目录保留 `main.py`、所需辅助模块及 `可选算法/` 中的算法示例。14 道题的具体实现位于对应 `main.py` 的成对“作答区”标记内。执行顺序为任务 1 → 任务 2 → 任务 3、4 → 任务 5；任务 3 和 4 均依赖任务 1、2 的结果。

## 运行

Python 3.10 及以上，在仓库根目录执行：

```bash
python -m pip install -r requirements.txt
python main.py             # 完整运行
python main.py --task 3    # 运行任务 3 及其必要前置任务
```

程序运行时需要课程提供的三张输入 CSV，按以下路径放在仓库根目录：

```text
数据集/华辰设备制造有限公司/cn_devices.csv
数据集/德维工业服务有限公司/de_devices.csv
数据集/德维工业服务有限公司/service_cases.csv
```

本仓库只包含代码和依赖说明，不包含输入数据、报告、演示文稿或运行结果。没有输入 CSV 时，代码可以阅读，但完整数据处理流程不能运行。每次运行会生成独立结果目录；统计发布包含随机噪声，重新运行的发布值可能不同。

项目中的 `DEMO_TOKEN_KEY` 是公开的课程演示密钥，用于教学示例。
